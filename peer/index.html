Marrow Point Bakery

We bake the bread other kitchens put their lunch on.

What we supply

Rye, brioche, ciabatta, bagels, pita and the glaze that goes on the donuts. We sell to delicatessens, canteens and cafes, not to the public, so there is no counter here to queue at.

Our glazes are batch recipes. What goes into a batch depends on what we can buy that week, so we publish what a glaze is and not a breakdown of the batch that reached your kitchen. If you need a breakdown for a particular delivery, write to us with the lot number.

Our agent network

This site publishes an agent network so that a kitchen's own assistant can ask us about a product directly. It is two agents of declarative JSON and nothing else: no code is published here and nothing on this site runs a model.

A caller loads the network into their browser and runs it on their own model router, with their own key. We never see that key, and the router block in our manifest is there to be read, not obeyed.

  • /agents/agent-manifest.json — the site manifest
  • /agents/marrow_point.network.json — the network definition

The network is named by the URL /agents/marrow_point: the last path component is the network name and the path before it is the site base the manifest is read from.

What we are not

We are not anybody's allergen check. We answer a kitchen about a component; we do not know who is eating, what they avoid, or what else is on the plate. A kitchen that puts our bread on a plate owns the answer it gives its own customer, and ours is not a substitute for it.

Marrow Point Bakery is a demo peer site. It exists on its own origin so that a second site's runtime has somewhere real to load a network from.
